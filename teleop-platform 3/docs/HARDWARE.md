# 真机接入：必须在实验室完成的部分

## 先确定一套具体设备

Franka Panda/FER、FR3 和各代 UR 的接口、关节限制、操作系统与驱动兼容性不同。“Franka/UR”不足以生成可靠的真机启动配置。第一轮选实际可持续借用的一台机械臂，另一型号保留接口扩展。

| 信息 | 需要填写/确认 |
|---|---|
| 机械臂 | 厂家、确切型号、序列号、控制柜、系统版本、是否开放 FCI/RTDE |
| 工具 | 夹爪型号、控制接口、工具重量/质心、TCP、负载配置 |
| GELLO | 对应哪种机械臂拓扑、编码器/电机型号、ID、符号、零位、跨周方式 |
| 主机 | Ubuntu/内核版本、网卡、驱动与机器人系统兼容版本 |
| 安全 | 实体急停、持续使能装置、可用工作空间、实验室负责人 |
| 感知 | 相机型号、数量、帧率、安装位置、时间戳能力、是否有力传感器 |
| 网络 | 两端地址、受控局域网/VPN、RTT/抖动/丢包、独立本地控制网 |

基础物料：对应型号 GELLO 打印结构和紧固件、相应编码器/电机与线缆、厂家推荐串口/USB 转接器及供电、固定底座、控制主机、独立网线、实体急停/使能设备；视觉示教另需相机与安装支架。现有库存和设备型号未知，未编造价格或采购总额。

## 两条硬件路线

**Franka：**先核对官方兼容表。官方 FCI 文档要求 Linux 实时内核环境并建议控制主机直连控制柜。1 kHz 控制回调留在机械臂旁，避免在该回调内执行 Python 网络收发、日志写盘、图像编码或阻塞锁。远程目标进入容量为一的本地最新目标缓冲，由已验证的局部轨迹生成器做插值/限速/限加速度/限 jerk，并执行经过测试的故障停止路径。选择 libfranka 或对应版本 franka_ros2 的现成控制器作为基础，不把本工程 Python 循环直接接到 FCI。

**UR：**核对具体机器人代际和软件版本。RTDE 用于状态/输入同步，运动还需与对应控制脚本、官方 ROS 驱动或经审查的 ur_rtde 接口配合。先读状态，再验证 `servoJ` 等具体命令、周期、增益、lookahead 与停止接口。不要把不同型号的默认参数互相复制。当前代码没有调用这些真机 API。

**GELLO 输入：**本工程按已查阅的上游 `GelloAgent(port, dynamixel_config)` / `act` 接口提供可选封装。安装并固定上游 commit 后，填写 `configs/gello.example.json`，在仿真服务器下运行：

```bash
python -m teleop client --keyfile demo.key --gello-config configs/gello.example.json --duration 30
```

封装尚未在串口设备上测试。上游会应用符号/零位，不能再用相同标定重复转换。夹爪方向必须通过现场观察确认，必要时设置 `invert_gripper`。手柄读失败或阻塞时，服务器自己的有效期应触发保持；实体持续使能必须单独接入，终端 `a` 开关不能替代。

## 到现场的验收顺序

1. **只读连接：**按实验室手册检查工作空间、急停与工具负载；只读取关节/机器人状态，连续记录，不发送运动。
2. **确认坐标与标定：**逐关节核对正方向、单位、关节顺序和多圈范围；记录多组静态对应姿态，并用留出姿态验证。
3. **当前位置保持：**目标从读到的当前位置初始化，拒绝直接跳转到代码里的 home；现场操作者控制使能与停止。
4. **受限单关节运动：**由设备负责人确定实际速度、幅度和空间限制，逐关节测试。同步观测厂家错误、实际 q/dq、期望 q/dq 与跟踪误差。
5. **故障注入：**在已批准的小范围动作中，分别停操作进程、断网、注入迟到/乱序、阻塞记录器、触发硬件急停；测停止触发时间和真实制动距离。不能只检查 Python 状态变为 HOLD。
6. **局域网同构遥操作：**完整核对夹爪、碰撞模型、工具/TCP 与有效期；完成连续运行和数据回放。
7. **视频与跨地域：**先量测相机曝光到显示的延迟，再开展远程任务。操作者“看到”的状态延迟可能远大于关节指令传输延迟。

每一步保留配置、软件版本、校准记录、日志、故障截图与现场签字。前一步未通过，不把后一步标为完成。

## 精度和时延怎么验收

关节跟踪误差应注明参考时间对齐方式、是否延迟补偿；末端绝对精度需经验证的运动学/工具标定或外部测量。关节 RMSE 小不保证末端绝对误差小。

延迟至少区分：手柄采样到目标接受、目标到机械臂响应、相机曝光到操作端显示、端到端人机回路。无可靠同步时，直接报告 RTT/确认延迟及其范围，不把 RTT/2 当成测得的单向延迟。

本地参考配置中的 120/150 ms 是软件有效期/看门狗参数，不是实机安全认证值；与伺服周期、停车距离、网络预算、最大速度共同决定。物理停车不能用本次仿真“速度置零”来验证。

## 本次没有接通的接口

真实 Robot 适配器、厂家停止函数、实体使能、工具与碰撞配置、相机/力觉、夹爪驱动均待设备信息确定后实现与现场测试。`RealRobotUnavailable` 故意拒绝运动。解除占位必须同时交付上述本地控制与停止路径，不能仅把类名改成某个厂家 SDK。
