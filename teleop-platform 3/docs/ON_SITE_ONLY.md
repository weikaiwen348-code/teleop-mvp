# 只把这些事情留给现场

v0.3｜2026-10-04。若此次只汇报已完成的仿真工作，先做新手指南中的答辩电脑彩排；下面是真正推进原项目硬件目标时使用的清单。

## 第一趟：收集信息，不发送运动

请设备负责人带着确认。组员只需拍必要的铭牌/连接照片并填写已知值，未知就写“待确认”，不要猜；照片不必含人员面孔或无关实验室信息。控制密码、令牌、无线网络密码不填入此表。

| 需要的信息 | 现场填写 |
|---|---|
| 机械臂确切型号（Panda/FR3/UR 某型号） | 待填 |
| 控制柜与机器人系统版本 | 待填 |
| 厂家接口是否已开通，当前已有驱动/例程 | 待填 |
| 夹爪型号、接口、工具与负载配置 | 待填 |
| GELLO 结构适配哪台机械臂，关节/电机型号、数量、ID | 待填 |
| GELLO 是否已经装好、供电和 USB/串口连接 | 待填 |
| 电脑操作系统、Python、现有 ROS/驱动版本 | 待填 |
| 实体急停与使能装置的位置，谁负责停止 | 待填 |
| 实验室现场负责人及允许的实验范围 | 待填 |
| 有哪些相机/力传感器，是否已经可读 | 待填 |
| 是否只能本地使用，是否有受控局域网 | 待填 |
| 型号/连接照片的文件名 | 待填 |

完成标准：设备负责人确认表中信息准确。先拿到这些信息，才可以为对应设备写具体安装、只读和标定步骤；现在不要填示例参数后尝试运动。

## 后续必须现场核实的动作

| 现场工作 | 组员最简单的动作 | 必须由谁把关 | 可由我继续做的软件工作 |
|---|---|---|---|
| 只读接入 | 按设备负责人批准的步骤运行、保存日志 | 熟悉厂家设备的人 | 型号对应的读取程序、日志检查 |
| GELLO 标定 | 按提示摆静态姿态、记对应读数 | 设备/控制负责人 | 拟合零位、方向、比例，输出留出验证报告 |
| 机器人停止路径 | 观察并记录被批准的测试 | 设备负责人操作和急停保障 | 对接厂家停止接口、分析触发时序 |
| 小范围跟随 | 按明确给定的范围操作手柄 | 现场负责人持续监督 | 约束与错误处理代码、轨迹分析 |
| 相机/任务数据 | 按任务要求操作并标注结果 | 任务负责人 | 同步、格式转换与检查脚本 |

真实机器人适配、厂家停止和实体使能接口还未实现。它们不是简单的勾选项；信息齐全后仍需软件开发和现场联合验证。不要让初学者自行调厂家伺服参数、绕过保护或把示例 `home` 下发给真机。
