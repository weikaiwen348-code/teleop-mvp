# 网页入口与运行边界 · v0.3

新手使用 `python run.py demo` 或启动菜单 `1`。它自动创建新的 `runs/manual-…`、选择空闲端口、打开浏览器，并在保存后自动结束服务、生成 HTML 数据检查报告。

开发者仍可运行 `python -m teleop ui --port 0 --open-browser`；输出目录省略时自动生成，明确指定时必须不存在。这个旧式服务入口保存后需在终端按 Ctrl+C 退出。浏览器必须支持 WebGL。

HTTP 只绑定 `127.0.0.1`，写请求要求随机 token。页面的 Web Worker 单独维护心跳；命令含 `client_id` 和递增 `input_seq`，一段控制只允许一个页面持有控制权，重复或其他页面的命令会拒绝。本地复位清理持有页面和序号记录。刷新导致旧页面身份丢失时，关闭多余页面并复位后重新使能。此机制是本机误操作隔离，不是多用户权限系统。

有效期为 120 ms，接收看门狗为 150 ms；到期进入 HOLD。每条运动命令都必须携带当前使能 epoch，HOLD 后需重新对齐和使能。后台同时检查实际墙钟周期；ACTIVE 期间间隔超过配置周期的 2.5 倍会进入 `FAULT/control_deadline`，物理引擎仍按固定步长推进。不要以放宽阈值掩盖电脑负载问题。

“结束并保存”后等待 `finalized`。`summary.complete` 只有记录、导出、关闭流程都成功才为真，保存或 NPZ 导出失败显示红色错误。原始 `metadata.complete` 只表示 JSONL 记录已完整关闭，含义不同；数据检查会一起核对摘要与 NPZ。

关闭网页不等于结束服务器；它会停止输入，让控制进入保持，后台可能继续记录。优先使用“结束并保存”。终端 Ctrl+C 会走清理路径，强制杀进程/断电不保证完整写入。

速度 0.4 rad/s、加速度 1.0 rad/s² 是仿真示例。模型保留重力、惯性和手指动力学，但没有实机动力学辨识、主动避碰或力反馈。HOLD/ESTOP 是数值冻结，不是厂家停止实现。

新网页记录 `human_collected=null`，表示程序无法核实谁在操作。随包历史 `manual_demo_episode` 是自动操作浏览器生成的记录；真正由组员拖动时也应另外记操作者、任务、日期和 episode 名称，再审核标注。两者均是仿真数据。
