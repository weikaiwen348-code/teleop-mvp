# 团队最少任务与交接

v0.3｜2026-10-04。软件审查、修复、自动自检、数据检查和指南已经准备好。组员不需要从零写代码。

## 本次仿真答辩

| 任务 | 谁来做（姓名由组长填写） | 怎么算完成 |
|---|---|---|
| 确认老师接受的汇报范围、时长 | 组长：____ | 记录“软件仿真阶段”和未完成目标如何说明 |
| 确认 GitHub 地址与访问范围 | 仓库负责人：____ | 正确链接，当前连接能读取；目前仍为 404 |
| 实际电脑启动→菜单 2→菜单 1 | 演示负责人：____ | 自检通过，自己操作一次并保存，保留 runs 目录 |
| 打开 PPT/视频，核对身份信息与排版 | 材料负责人：____ | 本机可播、字体正常，讲稿与实际工作一致 |
| 全组按时长彩排 | 每人 | 能讲清完成范围和负责部分 |

同一人可兼任。其他组员先看指南前 3 节、约 40 秒视频和常见问答。没有要求每个人安装开发环境、运行自动浏览器录制或研究所有源代码。

## 原项目后续路线

先按 [现场信息表](ON_SITE_ONLY.md) 收集设备型号/版本/连接和现场负责人确认。之后才能继续真实驱动、只读、标定、停止、受限运动、相机和远程测试。当前不是“只差插线”，也不是已经完成这些硬件工作。
