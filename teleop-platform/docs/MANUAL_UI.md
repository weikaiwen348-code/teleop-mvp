# 人工操作界面与运行边界

`python -m teleop ui --output runs/manual-01 --open-browser`，地址 `http://127.0.0.1:8080`。端口占用时用 `--port 8081`；输出目录已存在时改用新目录。首次装依赖 `python -m pip install -e '.[demo]'`。

浏览器必须支持 WebGL。若 3D 页面空白，更新浏览器或启用图形加速；查看页面错误提示。HTTP 界面仅绑定本地回环地址，写请求需要随机控制 token。不要把本地页面当成可直接公网部署的服务。

Python 控制与采集在线程中独立运行。浏览器的 Web Worker 独立请求短有效期，再发送当前滑块目标，避免 3D 绘图阻塞心跳。有效期为 120 ms，接收看门狗为 150 ms；到期进入 HOLD，更新使能 epoch，旧指令不会自动恢复运动。这个机制检测输入端连接和发送状态，不检测操作者是否真的握持了实体安全开关。

速度限制 0.4 rad/s、加速度限制 1.0 rad/s² 是本仿真示例配置。公开 Panda 模型使用自己的位置执行器，保留重力、惯性和夹爪动力学；未实现主动避碰、力反馈或动力学参数辨识。HOLD/ESTOP 使用数值冻结；任何实体机械臂接入都需要替换为厂家控制和实体安全停止路径。

点击“结束并保存”后，等待“保存完成”，再退出终端。保存过程中，记录写盘失败会显式报告；不静默丢样本。非 ACTIVE 行保留并标记 valid=False。`complete=True` 仅表示该段轨迹完整写入，不表示任务成功。

工程中的 `manual_demo_episode` 是自动操作滑块和按钮产生的可复现演示。用户自行拖动滑块记录的轨迹才是人工输入采集；二者都属于仿真轨迹，不能称为真实机械臂示教数据。
